Ajay — Portfolio (3D cinematic intro)

WHAT'S HERE
  index.html        the page
  css/style.css     styles
  js/intro.js       the 3D WebGL intro (three.js)
  js/site.js        typewriter, scroll reveal, k-means tile
  libs/three.module.min.js   three.js, self-hosted (no CDN needed)
  assets/ajay.jpg   your photo (swap this file to change it)

DEPLOY (GitHub Pages)
  Put all of these at the repo root (or in /docs), keeping the folder
  structure exactly. Commit + push. That's it — it's a static site.
  Because it uses ES modules, open it via a URL (GitHub Pages / any
  server), not by double-clicking the file.

TWEAKS
  - Replace your photo: drop a new image in as assets/ajay.jpg
  - Debug the intro slowly in a browser: add ?slow=6 to the URL
  - Reduced-motion visitors automatically skip the intro
